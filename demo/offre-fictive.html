Qui sommes-nous

Lumen Atelier édite un logiciel de planification pour les ateliers de réparation de vélos. Nous sommes une équipe de 14 personnes à Lyon et nos clients sont des artisans qui utilisent l'outil toute la journée. Chaque modification passe par une relecture de code et se déploie plusieurs fois par semaine.

Vos missions

  • Faire évoluer l'application web avec le reste de l'équipe produit
  • Concevoir des API et des écrans simples à utiliser pour nos clients
  • Relire le code de vos collègues et améliorer la chaîne de déploiement

Profil recherché

  • Vous maîtrisez React et TypeScript, et vous avez déjà mis en production une application web.
  • Vous connaissez Node.js côté serveur.
  • Vous avez au moins 2 ans d'expérience dans le développement web, alternance comprise.
  • Une pratique de la CI/CD est indispensable, celle de PostgreSQL et de Docker est un atout.

Conditions

CDI, rémunération de 45 à 52 k€ brut annuel selon expérience, mutuelle prise en charge à 100 %, deux jours de télétravail par semaine.
